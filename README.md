# Kit do Creator Hub

As instruções e as ferramentas abertas do kit de edição de vídeo do [Creator Hub](https://hub.creatorflowia.com). O kit depende do servidor do Creator Hub e só funciona com a assinatura ativa.

A instalação e o uso são ensinados nas aulas da área de membros.

As fontes Anton e Montserrat são distribuídas sob a SIL Open Font License 1.1 (arquivos `OFL-*.txt`).
